# موقع وهج

نسخة عربية ثابتة ومتجاوبة من موقع وهج.

## المعاينة

افتح `index.html` مباشرة في المتصفح.

## الملفات

- `index.html`: الصفحة كاملة، بما في ذلك التنسيق والتفاعلات.
- لا يعتمد الموقع على شعار مصوّر؛ تظهر كلمة «وهج» نصيًا.

## قبل النشر

1. ربط نموذج تسجيل الاهتمام بخدمة استقبال بيانات.
2. إضافة روابط حسابات وهج الرسمية ووسيلة التواصل.
3. مراجعة أي معلومات نظامية عن صفة المنظمة وموقعها.
4. إضافة أرقام الأثر وقصص المشاركين بعد اعتمادها.
