# هوية وهج البصرية

اتجاه أولي مستمد من الموقع الجديد.

## الفكرة

- العلامة الأساسية: كلمة «وهج» دون رمز منفصل.
- اللون الأساسي: `#5146C8`.
- الخط المقترح: IBM Plex Sans Arabic.
- اللغة البصرية: شبكة، دائرة، خط، مثلث.
- الدائرة تمثل الفكرة، والخط يمثل التوجيه، والمثلث يمثل المنتج.

## الملفات

- `brand-guide.html`: لوحة الهوية والتطبيقات.
- `wahaj-pattern.svg`: العنصر الهندسي بصيغة متجهية قابلة للتكبير.
- `mockups/stationery-mockup.png`: البزنس كارد والمطبوعات والشهادة.
- `mockups/booth-mockup.png`: تصور بوث وهج.
- `mockups/classroom-mockup.png`: تصور الفصل التدريبي.
- `mockups/mascot-exploration.png`: استكشاف أولي للتميمة.

## المرحلة التالية

بعد اعتماد الاتجاه، تُبنى ملفات الاستخدام النهائية: قوالب السوشال، شهادة، عرض تقديمي، بطاقة دورة، وتوقيع بريد.
